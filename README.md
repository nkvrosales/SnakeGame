# 🐍 Snake💕: A Special Valentine's Edition

A personalized, romantic twist on the classic Snake game, specifically designed as a 6-month anniversary surprise for **Lara**. Built with JavaScript, HTML, and a whole lot of love.

## 💖 The Story
This isn't just a game about eating food to grow longer. It’s a gamified love letter! Once the game ends, the player is presented with a heartfelt message and a very important question: *"Will You Be My Valentine?"*

## ✨ Features
- **Personalized UI:** Custom themes using the Pacifico and Poppins fonts with a romantic pink/purple aesthetic.
- **Dynamic Gameplay:** The snake speeds up as you eat more hearts, increasing the challenge.
- **Sound Effects:** Custom Web Audio API tones for eating, game over, and even a "wobble" sound if they try to click "No."
- **Valentine's Logic:** - A **"Runaway No" button**: If the user tries to click "No," the button shrinks and moves away.
  - **Celebration Modal:** Includes a custom confetti animation using emojis (❤️, ✨, 💝) when "Yes" is clicked.
- **Cross-Platform:** Includes a custom-built mobile D-Pad and swipe gesture support for playing on phones.

## 🛠️ Technical Stack
- **Frontend:** HTML, CSS (Flexbox/Grid, Keyframe Animations)
- **Logic:** JavaScript
- **Graphics:** HTML5 Canvas API

## 🕹️ How to Play
1. **Desktop:** Use your **Arrow Keys** or **WASD** to move the snake.
2. **Mobile:** Use the on-screen **D-Pad** or **Swipe** directly on the game canvas.
3. **Objective:** Collect the pulsing hearts (❤️) to increase your score.
4. **The Goal:** Reach the "Game Over" screen to unlock the surprise message for Lara.
